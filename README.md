# **Hoteler**

## Description
### _TThe goal of the project is to create an app that partially replicates the hotel booking process. The app's purpose is to allow customers to book a hotel room remotely._

## Technologies
### _Project is created with Python 3.11_

## Setup
### _Clone this repo to your desktop and run **poetry install** to install all the dependencies._

## Usage
### _After you clone this repo to your desktop, go to its root directory and run **uvicorn src.main:app --reload**. To launch the frontend in a new terminal go to hotel/frontend and run **npm run dev**_
